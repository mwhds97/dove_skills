# 王国保卫战Dove版 项目约定

> **注入索引**：只留「症状/触发 + 结论 + 标识」；细节 → 技能 `kr-dove-*` / 插件 README / 当日日志。
> 插件：`johnny_deadeye`·`hero_viper`·`ember_hero`·`hero_zezitra`·`kr6_powers`
> ⭐ **移植数值口径**：移植类数值改动**由用户定**；自创可自由调平衡。

## 五条最高优先级
1. **原版移植禁止"平衡性调整"**：须 1:1；要调只给**原始值+偏离量**交用户定。
2. **回血无 `U.heal`**：直改 `health.hp` + `km.clamp(0,hp_max,hp)`（scripts:5343）。
3. **加新技能字段三处齐**：`config` + `balance DEFAULTS & apply()` + `tt.hero.skills.<x>.<键>` ⇒ 漏模板 = nil 静默失效。
4. **校验脚本期望值易过期**：用户改平衡后 FAIL 假红 ⇒ 先查代码实际值 + 问用户。
5. **版本号由用户定**。

## ⭐⭐⭐ 三条「现象≠原因」血案（2026-10-18）
- **`kui.lua:585 stack depth` = children 有环**，非视图问题：环让 `G.push/pop` 失衡、污染整个渲染 ⇒ 先查自环。
- **`self._base:initialize(...)` 用冒号=灾难**：self 变类表 ⇒ 写进 middleclass `__instanceDict` ⇒ 所有实例共享 ⇒ 延迟父类必须点号+显式 self。
- **`GGLabel:_fit_text` 字体塌陷**（gg_views.lua:87-131）：1 号仍放不下 ⇒ `G.setFont(nil)` 崩，且构造期不跑（崩首帧）⇒ label 包 `harden_label`。

## 写 Dove UI/素材（细节见 `kr-dove-ui-panel`）
- ⭐⭐⭐ **写 UI 前先扫本体资源名**；字体白名单=`font_subst.lua`；`GG9View` 尺寸不足返 nil；**缩放只能 `scale`**。
- ⭐⭐⭐ **kui alpha 是 0~1**（非精灵 0~255）；**子视图正序绘制**（`kui.lua:674`）⇒ **后 add 的在最上层**（写反会盖住内容）。
- ⭐⭐⭐ **纯逻辑实体别继承 `decal_scripted`**（每帧 `animation idle not found`）⇒ 裸 `register_t`+`add_comps("pos","main_script")`；`animated=false` 时 `name` 写完整帧名。
- ⭐⭐⭐ **`db_atlas` 单表、后加载者覆盖**；本体图集按需装卸**按名删帧** ⇒ 同名帧连带删（火雨事故）⇒ 插件帧+动画名都**独占前缀**（`kr6p_`）。
- ⭐⭐⭐ **本体删帧**：`power_button_mask_*` 已删 ⇒ 引用它的插件须重写 `update`。
- ⭐⭐ **弹窗 z 顺序**：其他→面板→可见弹窗（`PopUpView` 子类须压面板之上）；判定 `not c.hidden`。
- ⭐⭐ **两套输入不能混用**：桌面=自身 `_editing`；安卓=本体 `sm.numeric_keyboard`，安卓分支**绝不能设 `_editing`**。

## 引擎硬规则
- ⭐⭐ **塔升级/出售/摧毁 = 命令式 API**（`TU.upgrade_tower/sell_tower/destroy_tower`）；旧标志 `e.tower.sell/upgrade_to` 全失效且静默。→ `kr-dove-tower-port`
- ⚠⚠ **备份脚本别先 `io.open(path,'w')` 再读备份**：`'w'` 立刻截断（balance.lua 中招过）⇒ 先读进内存再写回。⚠ Git Bash `/tmp` ≠ Python 的 `C://tmp`。
- 模板注册/修改必须写 `level:init()`。环境：`random`→`math.random`；`io.open` 打不开中文路径；log 用点号。⚠ **LuaJIT = 5.1 ⇒ 无 `table.pack/unpack`**。
- ⭐⭐ **require 模块名须与引擎逐字一致**（写错崩在随机位置）。崩溃位置 ≠ 原因；插件报错后游戏自动禁用 ⇒ 修完手动重启用。
- ⭐⭐ **`main_script.update` 首帧陷阱**：引擎只 create 一次、每帧 resume 同一个 ⇒ 每帧结算必须改外层协程。
- ⭐⭐ **`store.tick_ts` 秒**；`fts(10)`=0.333s；`dps.damage_every` 裸秒。
- ⭐⭐⭐ **脚本建的特效必须自己设 `sprite.ts=store.tick_ts`**（默认 0 ⇒ 恒停末帧=静态）。
- ⭐⭐⭐⭐ **`E.Load()`（大写）每次进关 `table.clear(entities)` + 从 `entities_backup` 恢复**（entity_db.lua:26-43）⇒ 运行期改的模板一开局就被抹。须 `HOOK(E,"Load")`（不只小写 `load`）+ 注册后写回备份。症状：PROBE 新值、进关旧值，只有重启对。
- ⭐⭐⭐ **`tween.remove` 默认 true**（components.lua:120）⇒ 播完即移除；⚠⚠ **`tween_prop.loop=true` 时 `finished` 恒 true**（tween.lua:310/318）⇒ **首帧就被移除**（症状：特效闪一帧+数值回退）⇒ 循环/常驻必须 `tween.remove=false`。
- ⭐⭐⭐ **`health.hp` 初值是 nil**（components.lua:27），实体进 `simulation` 才由 `systems/health.lua:583` 填 hp_max ⇒ **跨实体读 hp 一律先判 `health.dead` 或 `type(hp)=="number"`**。军营造兵是 create→queue_insert→**立刻**进 `b.soldiers`（scripts.lua:2045），那个兵 hp 还是 nil ⇒ 直接比必崩（皇家号令 2026-10-20 事故）。
- ⭐⭐ **移植兵种必设 `ui.click_rect`**（基类 20×25 太小）= (画布盒−anchor×画布)×scale，只取 idle+走 帧。
- ⭐⭐⭐ **判实体存亡用 `store.entities[id]==e`**（对象池让 `health` 骗人）；召唤物绑主人命期必加兜底寿命。
- ⭐⭐ **`E:create_entity` 四补**：quickcopy 深拷贝不污染模板；clone→create 换契约；P/GR 自 require；移除 block 友军前 `U.unblock_target`。
- ⭐⭐ **Dove 是 KR1 二次开发 ⇒ 搬机制前必查回归**：克隆敌人 `nav_path=nil` 崩 path_db；`soldier.pet` 已删；敌模板无 `nav_rally`；`find_soldiers_in_range` 丢 `v.soldier` 前置（友军 buff 传 `filter_func`）。
- ⭐⭐ **plugin_globals 注入的 helper 与引擎模块撞名**（E/U/SU/RT/AC/fts…）⇒ 文件级 local 遮蔽；`scripts.GR/P/S/KF` 一律 require。
- ⭐⭐ **多条静默失真**：帧名被抢/alias 不同步；描述串「数字+%」写 `%d%%`；`_()` 缺键返回键名。
- ⭐⭐ **Dove 更新会改 i18n 键 / 删帧** ⇒ 插件自带每个文案键（`locales/*.lua` 是死文件，生效的是主入口写 `i18n.msgs`）；外部帧过 `sprite_exists()`。
- ⭐⭐ **所有 CD 乘 `tower.cooldown_factor`**：收口 = `U.tower_ready_to_use_power` / `ready_to_attack`；文案「每隔 X 秒」也乘 `tcd`。⚠⚠ **格式串绝不能有裸 `%$`** ⇒ 占位用 `%s`。

## 数值三档（细节见 `kr-dove-plugin-config`）
①强度项→面板；②开发期常量→balance 固定值区；③只用一处→写死模板。⚠ 同一数值常有两副本 ⇒ **代码读哪张就往哪张写**。
- ⭐⭐ **改配置项 = 六处联动**：模板字面量 / balance.DEFAULTS / apply / config 三件 / probe / README。
- ⭐⭐ **面板默认值来自 balance 字面量、运行时值来自 `config.lua`（经 apply）** ⇒ 不一致时"默认"与实机值分叉（探针抓）。⚠ 浮点需容差（`14/30`），否则每次保存多写一键。
- ⭐⭐⭐ **面板值存在「共享存档」`%APPDATA%/LOVE/kingdom_rush_dove/game_params`**（不在插件目录）⇒ dev 与 AppData **读同一份**，切换测试环境会互相"继承"实测值；`compare_plugin_sync.py` 看不到它，别当"dev 干净"的证据。查法：直接读文件对齐 `<entry>_config.lua`。

## 经验 / 其它
- ⭐⭐ **手搓 `damage` 的 nil 陷阱**：`d.damage_type = nil` 会覆盖模板默认 DAMAGE_TRUE ⇒ `health.lua:655` 抛类型错。一律 `or rawget(_G,"DAMAGE_TRUE")`。
- ⭐⭐ **mod 叠加**：`resets_same` 默认 true ⇒ 同类 mod 唯一 ⇒ DPS=单次伤害÷damage_every；**不能**用 `allows_duplicates` 叠层。
- ⭐⭐⭐ **界面标度 vs 引擎比例**：百分比字段引擎 0~1、界面 ×100 ⇒ 用户说「1.5」按界面标度、代码 `*0.01`；标签必须标标度。
- ⭐⭐⭐ **降敌人护甲只有 `SU.armor_dec` 是真的**：`bullet.reduce_armor` 只改这一发。⚠ Boss `armor_resilience=0.5` ⇒ 降甲减半。
- ⭐⭐ **移植机制先找本体同款实现照抄**（`kr1/spells/*.lua`）：本体已踩过的时序坑别再手搓一遍（皇家号令 l2b 补兵 = 只看 `health.dead` + `queue_remove`）。
