# 王国保卫战Dove版 项目约定

> 注入索引：只留「症状/触发 + 结论 + 标识」；细节 → 技能 `kr-dove-*` / 插件 README / 当日日志。
> ⭐ **移植数值口径**：移植类数值改动**由用户定**；自创可自由调平衡。

## 五条最高优先级
1. **原版移植禁止"平衡性调整"**：须 1:1；要调只给**原始值+偏离量**交用户定。
2. **回血无 `U.heal`**：直改 `health.hp` + `km.clamp(0,hp_max,hp)`（scripts:5343）。
3. **加新技能字段三处齐**：`config` + `balance DEFAULTS & apply()` + `tt.hero.skills.<x>.<键>` ⇒ 漏模板 = nil 静默失效。
4. **校验脚本期望值易过期**：用户改平衡后 FAIL 假红 ⇒ 先查代码实际值 + 问用户。
5. **版本号由用户定**。

## ⭐⭐⭐ 三条「现象≠原因」血案（2026-10-18）：`kui` stack depth=children 有环（push/pop 失衡污染渲染）；`self._base:initialize` 冒号=全实例共享；`GGLabel:_fit_text` 1 号仍放不下 ⇒ `G.setFont(nil)` 崩 ⇒ label 包 `harden_label`。

- ⚠ **面板改数值要当场生效**：`register_t` 幂等 ⇒ `apply` 后重跑 `register_templates()`；别拿模板名当"已注册"守卫。

## 引擎硬规则
- ⭐⭐ **塔升级/出售/摧毁 = 命令式 API**（`TU.upgrade_tower/sell_tower/destroy_tower`）；旧标志 `e.tower.sell/upgrade_to` 全失效且静默。→ `kr-dove-tower-port`
- ⭐⭐⭐ **塔升级换实体**（`tower_utils.lua:87-106` 新建+移除旧）⇒ `tower.id` 变但 `:90` 继承 `holder_id` ⇒ 按塔归属状态一律用 `holder_id` 作 key；士兵侧 `soldier.tower_id` 需 `store.towers[id]` 反查。
- ⚠⚠ **备份脚本别先 `io.open(path,'w')` 再读**：`'w'` 立刻截断 ⇒ 先读进内存再写回。⚠ Git Bash `/tmp` ≠ Python 的 `C://tmp`。
- 模板注册/修改必须写 `level:init()`。环境：`random`→`math.random`；`io.open` 打不开中文路径。⚠ **LuaJIT=5.1 ⇒ 无 `table.pack/unpack`**。
- ⭐⭐ **require 模块名须与引擎逐字一致**（写错崩在随机位置）。崩溃位置 ≠ 原因；插件报错后游戏自禁用 ⇒ 修完手动重启。
- ⭐⭐ **`main_script.update` 首帧陷阱**：引擎只 create 一次、每帧 resume 同一个 ⇒ 每帧结算必须改外层协程。
- ⭐⭐ **`store.tick_ts` 秒**；`fts(10)`=0.333s；`dps.damage_every` 裸秒。
- ⭐⭐⭐ **脚本建的特效必须自己设 `sprite.ts=store.tick_ts`**（默认 0 ⇒ 恒停末帧）。
- ⭐⭐⭐⭐ **`E.Load()`（大写）每次进关 `table.clear(entities)` 并从 `entities_backup` 恢复**（entity_db.lua:26-43）⇒ 运行期改的模板开局被抹。须 `HOOK(E,"Load")` + 写回备份。症状：PROBE 新值、进关旧值。
- ⭐⭐⭐ **`tween.remove` 默认 true**（components.lua:120）⇒ 播完即移除；⚠⚠ **`loop=true` 时 `finished` 恒 true**（tween.lua:310/318）⇒ **首帧就被移除**（症状：特效闪一帧+数值回退）⇒ 循环必须 `tween.remove=false`。
- ⭐⭐⭐ **`health.hp` 初值是 nil**（components.lua:27，进 simulation 才由 health.lua:583 填）⇒ 跨实体读 hp 先判 `health.dead` 或 `type(hp)=="number"`。军营 create→queue_insert→**立刻**进 `b.soldiers`（scripts.lua:2045）时 hp 仍是 nil ⇒ 直接比必崩。
- ⭐⭐ **移植兵种必设 `ui.click_rect`**（基类 20×25 太小）= (画布盒−anchor×画布)×scale。
- ⭐⭐⭐ **判实体存亡用 `store.entities[id]==e`**（对象池让 `health` 骗人）；召唤物绑主人命期必加兜底寿命。
- ⭐⭐ **`E:create_entity` 四补**：quickcopy 深拷贝不污染模板；clone→create 换契约；P/GR 自 require；移除 block 友军前 `U.unblock_target`。
- ⭐⭐ **Dove 是 KR1 二次开发 ⇒ 搬机制前必查回归**：克隆敌人 `nav_path=nil` 崩 path_db；`soldier.pet` 已删；敌模板无 `nav_rally`；`find_soldiers_in_range` 丢 `v.soldier` 前置。
- ⭐⭐ **plugin_globals 的 helper 与引擎模块撞名**（E/U/SU/RT/AC/fts…）⇒ 文件级 local 遮蔽；`scripts.GR/P/S/KF` 一律 require。
- ⭐⭐ **多条静默失真**：帧名被抢/alias 不同步；描述串「数字+%」写 `%d%%`；`_()` 缺键返回键名。
- ⭐⭐ **Dove 更新会改 i18n 键 / 删帧** ⇒ 插件自带每个文案键（`locales/*.lua` 是死文件，生效的是主入口写 `i18n.msgs`）；外部帧过 `sprite_exists()`。
- ⭐⭐ **所有 CD 乘 `tower.cooldown_factor`**：收口=`U.tower_ready_to_use_power`/`ready_to_attack`；文案「每隔 X 秒」也乘 `tcd`。⚠⚠ **格式串绝不能有裸 `%$`** ⇒ 用 `%s`。

## 数值三档（见 `kr-dove-plugin-config`）
①强度项→面板；②开发期常量→balance 固定值区；③只用一处→写死模板。⚠ 同一数值常有两副本 ⇒ **代码读哪张就往哪张写**。
- ⭐⭐ **改配置项 = 六处联动**：模板字面量 / balance.DEFAULTS / apply / config 三件 / probe / README。
- ⭐⭐ **面板默认值来自 balance 字面量、运行时值来自 `config.lua`（经 apply）** ⇒ 不一致时"默认"与实机值分叉（探针抓）。⚠ 浮点需容差，否则每次保存多写一键。
- ⭐⭐⭐ **面板值在共享存档 `%APPDATA%/LOVE/kingdom_rush_dove/game_params`**（不在插件目录）⇒ dev 与 AppData **读同一份**，切环境会互相继承；同步脚本看不到它，查法：直接读文件对齐 `<entry>_config.lua`。

## 经验 / 其它
- ⭐⭐ **手搓 `damage` 的 nil 陷阱**：`d.damage_type=nil` 覆盖模板默认 DAMAGE_TRUE ⇒ `health.lua:655` 类型错。一律 `or rawget(_G,"DAMAGE_TRUE")`。
- ⭐⭐⭐ **`source_id` 必须是施加者，绝不填目标**：`damage_trace`（health.lua:489）按它记「输出」⇒ 填目标=敌人上输出榜。施加者消失回落主人/塔，都没有就**不设**；共享/分摊同样不设。
- ⭐⭐⭐ **实际伤害只在 `health.on_damage_applied(store,d,e)`**（health.lua:593，`:682` 写 `d.damage_applied`、`:690` 扣血后）：`d.value`=面板、`d.damage_applied`=结算值。⚠ 点号定义 ⇒ `HOOK(H,"on_damage_applied",fn)` 参数 `(next,store,d,e)`；被 dnum/pops/XP 占用 ⇒ 只能 HOOK。⚠ **秒杀/吞噬（`DAMAGE_INSTAKILL`/`DAMAGE_EAT`）damage_applied=整条血**（`utils.lua:2004` 特判）⇒ 按比例算收益必排除。
- ⭐⭐⭐ **叠层只能用「单实例原地更新」**：`do_tick` 里 insert **先于** remove（`simulation.lua:184`）⇒ 旧 mod 还在 `_applied_mods`，新建的被 `resets_same` 拒 ⇒ 减益已施加却无实体回收 = **永久残留**。改法：还原基准→改字段→重算→自写 `_expire_ts`（`modifier.duration` 不驱动到期）；到期置 `active=false` 但**留实体**供复用。
- ⭐⭐⭐ **`pairs` 迭代中插新键 = 未定义行为**：传播/连锁（诅咒传染、debuff 扩散）必须**先收集进数组、迭代结束再应用**，否则新项同帧被二次处理（症状：层数翻倍、远处连带）。
- ⭐⭐ **mod DPS 口径**：`resets_same` 默认 true ⇒ 同类 mod 唯一 ⇒ DPS=单次伤害÷damage_every；**不能**用 `allows_duplicates` 叠层。
- ⭐⭐⭐ **界面标度 vs 引擎比例**：百分比字段引擎 0~1、界面 ×100 ⇒ 用户说「1.5」按界面标度、代码 `*0.01`；标签须标标度。
- ⭐⭐⭐ **降敌人护甲只有 `SU.armor_dec` 是真的**：`bullet.reduce_armor` 只改这一发。⚠ Boss `armor_resilience=0.5` ⇒ 降甲减半。
- ⭐⭐ **移植机制先找本体同款实现照抄**（`kr1/spells/*.lua`）：本体踩过的时序坑别手搓第二遍（皇家号令 l2b 补兵 = 只看 `health.dead`）。
